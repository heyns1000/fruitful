One thing I actually believe about this work

A claim is only as strong as the command you'd run to check it. Everything in this page has that command sitting behind it — git log --merges, a live curl against a running Worker, a byte-diff between two repos' copies of the same file. Where I couldn't run that command, I said so instead of rounding up.

That's the whole trunk. Not a philosophy borrowed from an ancient tree — a habit, repeated enough times this session that it started to look like one.
